# Skill library

The canonical skill bodies live in `.claude/skills/`. This is the routing catalog, not a second set of instructions. All eight starter skills are house skills for maintaining the foundation.

| Skill | Use when | Canonical file |
|---|---|---|
| brain-setup | Install or resume this foundation | [SKILL.md](../.claude/skills/brain-setup/SKILL.md) |
| build-from-intake | Prepare business pages from supplied intake | [SKILL.md](../.claude/skills/build-from-intake/SKILL.md) |
| file-it | Turn new source material into current knowledge | [SKILL.md](../.claude/skills/file-it/SKILL.md) |
| catch-me-up | Orient to the current work and next task | [SKILL.md](../.claude/skills/catch-me-up/SKILL.md) |
| remember-this | Save a correction or durable decision | [SKILL.md](../.claude/skills/remember-this/SKILL.md) |
| grow-system | Decide how and where to add a capability | [SKILL.md](../.claude/skills/grow-system/SKILL.md) |
| build-skill | Turn a repeatable process into a tested skill | [SKILL.md](../.claude/skills/build-skill/SKILL.md) |
| support-session | Prepare and handle a bounded support exchange | [SKILL.md](../.claude/skills/support-session/SKILL.md) |
| send-email | "Email <person>": look up, draft in Outlook, show Fran, send only on "send" | [SKILL.md](../.claude/skills/send-email/SKILL.md) |

When a skill is added, give it one row with a concrete trigger. Update the root routing table only if it is a common entry point. For third-party skills, record source URL, version and license beside the catalog entry.

Templates: [skill](skill-template.md), [knowledge page](knowledge-template.md), [handoff](handoff-template.md).
