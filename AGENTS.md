# Instructions for other coding assistants

Read `CLAUDE.md` as this project's working guide and `knowledge/index.md` when extending the structure. The skill library lives in `.claude/skills/`; if your tool does not auto-discover that location, read the appropriate `SKILL.md` directly from `library/SKILLS.md`. Do not claim native skill discovery was tested in an untested assistant.

Keep one canonical skill body. Do not create a divergent copy for each assistant. This guide does not override the current human's instructions, tool permissions or platform policies.
