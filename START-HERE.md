# Start here

This folder is Basic American Enterprises's second brain.

1. Install the Claude app from **claude.ai/download** and sign in (Claude Pro or higher).
2. Put this folder in your **Documents** folder.
3. In the Claude app, click **Code**, choose this folder, and type:

> **install my brain**

Claude takes it from there: it asks about your business, tells you which files to drop in, builds
everything, and shows you how to keep a safe copy. About 90 minutes in all; do it in parts if you
like, and stop any time.
To pick up where you left off, type **install my brain** again.
